# Test0 Parallel Dataset GLB Generation

## Summary

Generated per-asset GLB files for the current test0 parallel dataset and
backfilled each asset annotation's `glb_size` field from the generated GLB file
size.

Dataset root:

```text
/cpfs/user/zhuzihou/assets/dedup_workspaces/test0_transitive_apply_parallel/dataset
```

## GLB Generation

The dataset already matched the normalized asset layout expected by
`scripts/convert_subset_usd_to_glb.py`:

```text
GRScenes_assets/<category>/<uid>/usd/<uid>.usd
```

The script writes GLB files to:

```text
GRScenes_assets/<category>/<uid>/glb/<uid>.glb
```

### Pilot

Ran a local pilot on 8 UIDs across different categories before submitting the
full job. All 8 generated GLB files were present, non-empty, and had the `glTF`
magic header. A second run over the same UIDs reported `skipped_existing: 8`,
confirming incremental behavior.

Pilot report:


## Annotation Backfill

The standard `scripts/backfill_asset_annotations.py --overwrite` path was
checked first, but it also recomputes USD render package sizes and is too broad
for this operation. For this dataset update, only `glb_size` needed to change,
so the backfill used the same size unit as the existing annotation convention:

```text
glb_size = bytes(glb/<uid>.glb) / 1024 / 1024
```
